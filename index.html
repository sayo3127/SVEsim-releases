개인정보처리방침

시행일 및 최종 수정일: 2026년 11월 24일

이 방침은 Manaria Library(Android 패키지명: com.sayo.Manarialib, 이하 “앱”)에 적용됩니다. 앱은 카드 정보 검색과 덱 구성을 돕는 도구입니다. 본 방침은 SVEsim 대전 시뮬레이터가 아닌 Manaria Library에 관한 것입니다.

개인정보의 수집 및 전송

앱은 회원가입이나 로그인을 요구하지 않으며, 개발자가 운영하는 서버로 사용자의 개인정보, 덱 목록 또는 앱 이용 기록을 수집·전송하지 않습니다. 앱에는 광고, 광고 식별자 추적, 사용자 분석 또는 원격 오류 수집 기능을 넣지 않았습니다.

기기에 저장하는 데이터

덱 이름·카드 구성 등 사용자가 만든 덱과 앱 설정은 사용자의 기기에 저장되며 기능 제공과 설정 유지에 사용됩니다. 카드 정보와 카드 이미지는 앱 및 Google Play의 설치용 에셋을 통해 제공됩니다. 앱 자체의 계정 서버나 클라우드 동기화 서버에는 저장하지 않습니다.

클립보드 접근

앱은 덱 코드 가져오기 기능을 위해 앱 화면을 열거나 다시 활성화할 때 클립보드의 텍스트를 확인할 수 있습니다. 덱 코드 형식인지 기기 안에서 판별하며, 클립보드 내용을 개발자 서버로 전송하지 않습니다. 사용자가 복사 기능을 누르면 덱 코드나 카드명을 클립보드에 기록합니다. 클립보드의 보관 및 다른 앱의 접근은 운영체제 설정과 동작에 따릅니다.

이미지 저장과 기기 권한

사용자가 덱 이미지 저장을 요청하면 앱이 생성한 이미지를 사진·갤러리 저장소에 저장합니다. 운영체제 버전에 따라 필요한 저장 관련 접근이 발생할 수 있습니다. 이 기능은 사용자의 다른 사진을 수집하거나 개발자에게 업로드하기 위한 것이 아닙니다. 저장한 이미지는 사용자가 갤러리에서 직접 관리·삭제할 수 있습니다.

외부 사이트와 배포 서비스

사용자가 카드 판매 사이트 연결을 누르면 외부 브라우저에서 Card Rush(www.cardrush-sv.jp)의 카드 검색 페이지를 엽니다. 이때 선택한 카드 번호가 검색어로 주소에 포함됩니다. 외부 사이트는 접속 시 IP 주소 등 일반적인 웹 접속 정보를 처리할 수 있으며 해당 사이트의 방침이 적용됩니다.

Google Play를 통한 설치·업데이트 및 운영체제의 백업 기능은 Google 또는 운영체제 제공자의 정책과 사용자 설정에 따라 동작합니다. 개발자는 이들 서비스가 독립적으로 처리하는 정보를 앱 자체에서 수집하는 것으로 간주하지 않습니다.

제3자 제공 및 판매

개발자는 앱이 기기에 보관하는 덱·설정·클립보드 내용을 제3자에게 제공하거나 판매하지 않습니다. 사용자가 직접 복사·저장·공유한 정보와 외부 사이트에 직접 제공한 정보는 사용자가 선택한 앱이나 서비스의 정책을 따릅니다.

보관 및 삭제

덱과 설정은 기능 유지를 위해 기기에 보관됩니다. 앱 안에서 덱을 삭제하거나, Android 설정에서 앱 저장 데이터 삭제 또는 앱 제거를 통해 로컬 앱 데이터를 지울 수 있습니다. 갤러리에 저장한 이미지는 앱 제거와 별도로 삭제해야 할 수 있습니다. 운영체제의 백업 데이터가 있는 경우 백업 관리·복원 여부는 해당 서비스 설정을 확인해 주세요.

이메일로 문의하면 발신 이메일 주소와 문의 내용이 개발자에게 전달됩니다. 이는 문의 응답 및 문제 해결에만 사용하며, 처리가 끝나 더 이상 필요하지 않은 정보는 삭제합니다. 법령상 보관 의무가 있는 경우에는 해당 의무를 따릅니다. 문의 내용의 삭제를 원하면 아래 연락처로 요청할 수 있습니다.

안전한 처리

앱은 주요 이용 데이터를 기기 내부에서 처리하고, 기능에 불필요한 개인정보를 수집하지 않는 방식으로 설계되었습니다. 기기를 공유하거나 덱 코드·이미지를 외부로 공유할 때는 공개되는 내용에 주의해 주세요.

방침의 변경

앱 기능이나 데이터 처리 방식이 변경되면 이 페이지의 방침과 최종 수정일을 갱신합니다. 변경된 기능에 필요한 안내나 동의가 있다면 그 기능을 제공할 때 별도로 알립니다.
